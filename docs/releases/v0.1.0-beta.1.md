## 安装

1. 下载并运行 `PersonalKnowledgeBase-0.1.0-setup.exe`。
2. 如遇 SmartScreen，选择「更多信息」→「仍要运行」。
3. 首次启动会初始化 `%APPDATA%\PersonalKnowledgeBase\`，后端与离线模型随包提供，无需联网。
4. 可选：在「设置」中配置 DeepSeek API Key 并显式开启外联，启用 AI 对话与自动整理。

系统要求：Windows 10 1809+ / Windows 11 x64，4 GB 内存，约 600 MB 磁盘。无需 Python / Node.js。

## 本版内容

- 笔记 / TeX / 文件管理，标签、时间轴、软删除与版本保护
- 关键词 + 语义 + 混合检索，内置 `bge-small-zh-v1.5` 离线模型
- DeepSeek 流式对话、知识库工具调用与引用
- 摘要、打标、关联、画像、图谱等 AI 任务
- 重复提醒与桌面通知
- 学习计划、里程碑与进度
- 知识图谱浏览
- 本地优先与密钥隔离

## 安全说明

- 后端仅监听 `127.0.0.1` 随机端口，使用每次启动生成的 Bearer token
- API Key 仅存 Windows 凭据管理器，不写入数据库、日志或接口响应
- 外部 AI 调用默认关闭，需要用户显式开启
