## 1. 使用规则（所有工作树必读）

1. **开工前**：先同步 `main`，读本文件，确认目标任务的「状态」不是 `DONE`，也不是他人正在做的 `DOING`。
2. **领取任务**：把「状态」改为 `DOING`，把「最近更新」改为当天日期（`YYYY-MM-DD`），「负责人/工作树」填自己的工作树简称。
3. **完成任务**：状态改 `DONE`，「备注」写 PR/提交号与关键产物。
4. **遇到阻塞**：状态改 `BLOCKED`，在「阻塞与待决」表追加一行，写清需要谁提供什么。
5. **接口变更**：先改后端代码与 OpenAPI，再在「接口变更记录」追加一行；前端确认后填写确认日期。
6. **每日收尾**：在「工作日志」追加一行（只追加，不修改历史）。
7. **只改自己负责的行**；合并冲突时保留双方内容，按 ID 重新排序，不得删除他人记录。
8. 本文件只写状态、结论、链接；长篇说明放 `docs/` 并在备注中链接。

工作树简称：`后端` = `lwc/后端-test-tube-langchain`，`前端` = `lwc/桌面端页面-high-voltage`，`联调` = `lwc/中间关联接口调节-rocket`。

### 1.1 状态图例（机器可读，保持英文大写）

| 状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| `TODO` | 未开始 | `DOING` |
| `DOING` | 进行中 | `DONE` / `BLOCKED` / `PAUSED` |
| `DONE` | 已完成并自测通过 | 仅在返工时改回 `DOING` |
| `BLOCKED` | 被外部依赖阻塞 | `DOING`（阻塞解除后） |
| `PAUSED` | 主动暂停 | `DOING` |

> 状态列只允许上述五个值。脚本会校验。

## 9. 决策记录（只追加）

| 日期 | 决策 | 理由 | 影响 | 备选方案 |
| --- | --- | --- | --- | --- |
| 2026-11-24 | 后端采用 FastAPI + Pydantic v2 | Python 原生、OpenAPI 自动生成、异步流式友好 | 契约由代码导出，前端类型自动生成 | Flask、Django |
| 2026-11-24 | 前端采用 Electron + React + TypeScript | Node 生态成熟、Windows 打包稳定、与需求一致 | 主进程管理后端进程与安全边界 | Tauri、PyWebView |
| 2026-11-24 | 向量库采用 ChromaDB 嵌入式 | 本地私有化、零外部依赖、持久化简单 | 数据随应用目录迁移 | FAISS、Qdrant |
| 2026-11-24 | 关系库采用 SQLite + SQLAlchemy + Alembic | 单用户本地场景足够，迁移可控 | 后续可平滑切换 Postgres | Postgres |
| 2026-11-24 | JSON 字段统一 `snake_case` | 与 Python 一致，减少后端转换 | 前端仅在 mapper 层转换 | camelCase |
| 2026-11-24 | 流式使用 SSE 而非 WebSocket | 单向推送足够、实现简单、易重连 | 仅 `/agent/chat`、`/events/stream` 使用 | WebSocket |
| 2026-11-24 | 统一响应信封 `{code,message,data,request_id}` | 错误处理一致、便于前端集中映射 | 所有业务接口遵循 | 裸 HTTP 响应 |
| 2026-11-24 | 本地鉴权使用一次性本地 token | 桌面端私有化场景，无需账号体系 | token 由 Electron 主进程注入 | OAuth、账号密码 |
| 2026-11-24 | AI 模型仅接入 DeepSeek，禁止其他供应商与本地模型 | 用户明确要求 | `ModelGateway` 只实现 DeepSeek 适配器；设置页只提供 DeepSeek 配置；未配置 Key 或未开启外联时 AI 功能禁用 | 多供应商、Ollama 本地模型 |
| 2026-11-24 | DeepSeek 采用 OpenAI 兼容 HTTP 接口，模型白名单为 `deepseek-chat` / `deepseek-reasoner` | 与 LangChain 现有集成兼容，接入成本低 | 只维护一个适配器；新增模型需随版本更新白名单并登记 | 自建代理、其他 SDK |

## 12. 定时扫描协议

### 12.1 扫描命令

在仓库根目录执行：

```bash
python scripts/check_progress.py --file docs/开发过程.md
```

可选参数：

```bash
# 自定义逾期阈值（默认 3 天）
python scripts/check_progress.py --file docs/开发过程.md --stale-days 2

# 输出 JSON（供程序消费）
python scripts/check_progress.py --file docs/开发过程.md --json
```

### 12.2 扫描内容

- 各看板任务数与完成率
- `DOING` 超过阈值的逾期任务
- `BLOCKED` 未解决项
- 依赖未完成却已 `DOING`/`DONE` 的任务
- 重复 ID、非法状态、缺少负责人、日期格式错误
- 接口变更记录中「前端确认」为空的行

### 12.3 结果处理

- 扫描器**只读**，不得修改本文件。
- 发现异常时，由对应工作树在当天更新状态或补充阻塞说明。
- 定时任务每 30 分钟运行一次（本地时间 `:07` 与 `:37`），只汇报，不写入。

### 12.4 退出码约定

| 退出码 | 含义 |
| --- | --- |
| 0 | 无问题 |
| 1 | 有警告（逾期、阻塞、依赖未满足） |
| 2 | 有错误（非法状态、重复 ID、文件不可读） |
